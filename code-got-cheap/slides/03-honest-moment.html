Job hunting: layoffs.fyi counted ~135k tech layoffs in 2026 as of Oct 21 vs 122.6k for all of 2025. Still well below 2023 (~265k). Indeed software dev postings are still roughly 22–27% below Feb 2020.

Hiring: Greenhouse (6,000+ companies, 640M applications) has applications per job at 116 in 2022, 189 in 2023, 223 in 2024 and 244 in 2025. Their page also shows recruiter headcount down about 56%, but their regional pages disagree on the per-recruiter figure, so I don't quote that one. If you're hiring and drowning, you're not imagining it.

Skills: Sonar surveyed 1,100+ developers (press release Jan 8 2026). 96% don't fully trust AI-generated code is functionally correct, and only 48% always check it before committing. The skill of checking code is still very much needed, and a lot of people are skipping it.
