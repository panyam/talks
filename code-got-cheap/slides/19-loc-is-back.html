Lines of code is back, baby

Activity metrics

  • Lines of code written
  • % of code written by AI
  • Suggestion acceptance rate
  • PRs opened per engineer

Outcome metrics

  • Lead time to production
  • Change failure rate
  • Rework: code rewritten within weeks
  • Time PRs wait for review
  • Incidents and recovery time

Open on the cartoon and let the title do the work. Two clicks: activity metrics, then outcome metrics.

The cartoon is an original homage to the Seinfeld "I'm back, baby!" meme (George Costanza). If I want the real still, swap in an image I've sourced myself, the SVG sits in the .loc-art box.

Framing: the left column is fine to track, it tells you adoption is happening. It just shouldn't be the target on its own, because AI makes it very cheap to move. Goodhart's law: when a measure becomes a target, it stops being a good measure. Pair each activity number with an outcome from the right.

Atlassian DevEx 2026: 60% of developers say AI usage is treated as a productivity signal where they work. Worth mentioning neutrally, not as a criticism.

Joke: "Measuring developer productivity by lines of code was a bad idea in 1985. Measuring it by lines of code the robot wrote is the same idea, just with a bigger number."

Reminder of the perception gap: self-reported "I feel faster" surveys have the same problem.
