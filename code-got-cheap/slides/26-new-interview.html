The interview is changing

Fading

  • Reverse a linked list from memory
  • Unproctored take-homes
  • "No Googling"

Growing

  • AI-allowed coding rounds
  • Debug or extend existing code
  • Review a PR (sometimes an agent's)
  • "Walk me through your choices"

Some big companies now run AI-enabled rounds. Others make you promise not to use it. Ask which one you're in.

Examples. Canva (its own engineering blog, Jun 2025) expects backend, ML and frontend candidates to use AI tools, and replaced its CS fundamentals interview. Press-reported only, so say "reportedly": Meta has been testing an AI-enabled coding round since late 2025, Google is adding Gemini-assisted code comprehension rounds in H2 2026 for some teams, and Amazon's internal guidelines ban gen AI in interviews.

Steve Yegge has gone furthest and predicted we'll mostly stop doing technical interviews within a few years ("The Last Technical Interview", ~May 2026; I've only seen it secondhand, so paraphrase).

JetBrains 2026: 79% of developers believe employers will expect AI proficiency, up from 59% in 2024.

Why: when the model can solve the LeetCode problem faster than the candidate, the puzzle stops telling you anything. What still tells you something: judgment, debugging, reading code, explaining tradeoffs.

Joke: "The take-home still exists, it just comes with a follow-up call where you explain it while I watch."
