Yegge built Gas Town, an agent orchestrator, this year and has gone furthest on "let the agents run". He's also predicted that we'll mostly stop doing technical interviews within a few years ("The Last Technical Interview", ~May 2026, on his Medium; I only have it secondhand, so I'd paraphrase it rather than quote it).

Willison uses agents heavily and wrote the Agentic Engineering Patterns guide, and he's said he finds it "quite upsetting" that his line between vibe coding and careful engineering has started to blur.

Hashimoto (Ghostty, HashiCorp) uses AI daily. Ghostty's contribution policy asks contributors to disclose AI use and be able to explain their changes.

Ronacher (Flask) is a heavy agent user too. His follow-up post "The Final Bottleneck" says: "Historically, writing code was slower than reviewing code." … "I was the bottleneck all along."

Marcus has been tracking outages linked to AI-written code. His post title is a mouthful but it's the sceptic case in one line: compiling and passing the tests you were given isn't the same as correct, secure, maintainable software.

Majors' post is titled "AI enthusiasts are in a race against time, AI skeptics are in a race against entropy". Her point is that both sides are describing real things they've seen, which is where the rest of this talk sits.
