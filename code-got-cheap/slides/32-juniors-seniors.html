Advice by career stage

Dear early-career me,
  • Use AI to explain things, then check you can do them without it.
  • Ask it why code works, as well as asking it to write code.
  • Build something real and be able to explain every line.
  • Find people. Referrals and mentors beat cold applications right now.
P.S. Nobody knows what they're doing in year one. I certainly didn't.
Dear experienced me,
  • You've seen things break. Put that into reviews, docs and guardrails.
  • Learn to run agents well. It's a new skill, and it's learnable.
  • Mentor someone. The pipeline needs you.
  • Keep using the tools, even the ones you're sceptical about.
P.S. You don't need to rewrite the build system this weekend.

Two clicks, one postcard each. Read the P.S. lines, they're the laughs, and they're both at my own expense.

For juniors: interviewers can tell within minutes whether you understand what you shipped. Use the tools, and make sure you can explain what they produced. The Anthropic study (slide 13) backs this up: people who used AI to ask questions kept their understanding.

For seniors: you're the people who know what "almost right" looks like. Teams need a lot more of that now.
