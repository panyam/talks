# Stats for the webinar, latest editions (checked 2026-10-26)

[P] = read on the publisher's own page. [S] = secondary only, caveat before using on a slide.

## Stack Overflow Developer Survey 2026 (Oct 6 2026, 30,903 responses) [P]
https://survey.stackoverflow.co/2026/ai
- 83% use at least one AI tool; coding assistants 66%, chat 63%, agents/workflows 26%. 73% of users use them daily; 31% over four hours a day.
- Sentiment 62% favourable; 53% of early-career (1–5 yrs) vs 69% of 16+ yrs; 71% for daily users (blog).
- Trust (new question, n=14,304): 48.0% "when I can easily verify the output"; 16.3% many tasks but not important decisions; 16.3% low-risk only; 12.3% don't trust for most tasks; 6.6% including important decisions ("only 7%").
- Verification: run locally 76%, compare with codebase 64%, check tests/security 53%; only 10% use answers as-is.
- Only 16% say AI handles complex tasks very well.
- 79% want to build AI skills (blog). 59% avoid AI for some reason; skill loss/job replacement 17%.
- **Not asked in 2026:** "almost right" frustration, "ask a person", trust/distrust in accuracy. Do NOT compare 2025 trust (33%) with the 2026 "87% some trust" line on the overview page; different question.

## Stack Overflow 2025 (still the latest for these questions) [P]
https://survey.stackoverflow.co/2025/ai
- 84% use or plan to use; 46% distrust accuracy vs 33% trust; 66% "almost right, but not quite"; 45.2% debugging AI code more time-consuming; 75.3% ask a person when they don't trust AI.

## DORA [P]
- No 2026 State of AI-assisted Software Development yet; 2025 is latest (Sep 23 2025, ~5,000 respondents).
- 90% use AI at work; >80% believe productivity up; 30% little/no trust; AI positively related to throughput and product performance, negatively to delivery stability; "AI's primary role is as an amplifier". Median two hours a day with AI; 59% positive influence on code quality.
- 2026: "ROI of AI-assisted Software Development" (Apr 2026) is a model, not survey findings.

## JetBrains Developer Ecosystem 2026 (>15,000 devs) [P]
- 90% use AI coding agents at work at least weekly, 68% daily. https://blog.jetbrains.com/research/2026/08/ai-coding-agent-adoption-2026/
- ~47% of code fully agent-written, ~27% fully manual; ~31% "agentic coders" with 84% agent-generated. https://blog.jetbrains.com/research/2026/08/how-much-code-do-developers-really-let-agents-write/
- 79% believe employers will expect AI proficiency (59% in 2024); 43% ready to fully delegate code review (33%); 37% think AI will reduce demand for developers (28% in 2024). https://blog.jetbrains.com/research/2026/10/dynamics-of-sentiment-and-attitudes-toward-ai-among-developers/

## Sonar State of Code 2026 (Jan 8 2026, >1,100 devs) [P]
https://www.sonarsource.com/company/press-releases/sonar-data-reveals-critical-verification-gap-in-ai-coding/
- 96% don't fully trust AI code is functionally correct; only 48% always check before committing; AI = 42% of committed code; 38% say reviewing AI code takes more effort; 72% of AI users use it daily.

## Atlassian State of DevEx 2026 (Oct 20 2026) [P]
https://www.atlassian.com/blog/development/developer-experience-report-2026
- 87% say AI helps them ship faster; 72% have the same or more friction than before AI. 10+ hrs/week saved: 68% (2025) → 25% (2026). 65% regularly correct AI output. Only 17% of devs and 23% of leaders say their org has a clear AI strategy. 60% say AI usage is treated as a productivity signal.

## DX Q2 2026 (Jul 22 2026, 500+ orgs) [P]
https://getdx.com/news/dx-releases-q2-2026-state-of-ai-impact-in-engineering-report/
- AI-generated code 52.7% of all code (24% two quarters earlier, methodology changed). Median PRs per engineer per week 1.42 → 1.94 (+37%). Change confidence −6.1%.
